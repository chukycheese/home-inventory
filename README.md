# 우리 집 칸 (Home Inventory) 🌿

가볍게 기록하고 1초 만에 찾는 우리 집 살림 & 수납 인벤토리 웹앱

## 주요 기능
- **수납 위치 기반 공간 지도**: [팬트리, 주방, 드레스룸, 안방, 다용도실, 서재] 공간별 보관 위치 시각화
- **1초 초성 검색**: "ㅊㅇ" (치약), "ㅇㄷㅌ" (멀티어댑터), "ㄱㅈㅈ" (건전지) 등 초성 및 키워드 검색
- **소모품 재고 & 장보기 자동 연동**: 재고 상태 원터치 토글 (넉넉함 / 보통 / 부족함 / 품절). 부족함 체크 시 장보기 목록으로 자동 이동
- **부부 모바일 최적화**: 스마트폰 홈 화면 추가 및 반응형 UI 지원
- **데이터 저장**: 브라우저 `localStorage` 기반 즉시 저장 & 복원

## 로컬 실행 및 배포
```bash
# 로컬 개발 서버 실행
npx wrangler dev

# Cloudflare Workers 정적 사이트 배포
npx wrangler deploy
```
